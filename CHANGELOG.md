# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии проекта следуют семантическому версионированию.

## [Unreleased]

### Надёжность Gildra Runtime под конкуренцией и отказами

- Managed-git выполняется в контролируемом окружении: переменные, способные
  перенаправить команду в чужой репозиторий, вычищаются, hooks и fsmonitor
  недоверенного репозитория отключаются, у команд раздельные таймауты, а
  fetch получил ограниченные повторы без ретрая ошибки аутентификации.
- Lease получил монотонное поколение (fencing): «воскресший» writer после
  перехвата не может выполнить ни одну разрушительную операцию Runtime.
- Добавлен durable operation journal: после падения восстановление точно
  знает, какой шаг многошаговой операции завершился, и ничего не удаляет само.
- Жизненный цикл сессии больше не зависит от одной вкладки браузера: UI,
  процесс и lease — три независимых признака жизни.
- Merge стал crash-recoverable: явная state machine, целевая ветка двигается
  только последним шагом, конфликты никогда не разрешаются молча, политика
  слияния конфигурируема.
- Cleanup защищён от TOCTOU (planToken + повторная проверка под локом), а
  отклонённая операция больше не оставляет следов.
- Store пишет состояние с fsync файла и каталога, переживает сбой между
  записью и переименованием, умеет миграции схемы и безопасно отвергает
  состояние из более новой версии Runtime.
- Процессы и порты: явная абстракция бэкенда завершения, защита от
  переиспользования PID, порт не переиспользуется, пока на нём кто-то слушает.
- API: строгий loopback-allowlist Origin/Host, идемпотентные мутации,
  ограничения размера запроса, endpoints health/capabilities/diagnostics и
  запрет мутаций до завершения восстановления.
- Реестр проектов: безопасное принятие локального репозитория, проверка
  целостности canonical-репозитория и закрепление базы неизменяемым коммитом.
- Тесты доказывают инварианты, а не повторяют код: настоящие ОС-процессы над
  одним state-корнем (взаимное исключение, единственный владелец lease,
  непересекающиеся порты, перехват лока убитого процесса), симуляция падения в
  каждой точке многошаговой операции, стресс-набор на 50 конкурентных
  претендентов и гонки create↔cleanup. Именно они нашли пять реальных
  дефектов, не видимых при чтении кода.
- Контракт надёжности и честные ограничения задокументированы в
  `docs/runtime-reliability.md`.

### Мультипользовательская изоляция сессий (Gildra Runtime)

- Новый серверный плагин `@gildra/dsh-runtime`: реестр проектов с canonical-
  репозиториями, изолированный Git worktree + ветка `session/<user>/<id>` на
  каждую write-сессию, эксклюзивные write-lease с heartbeat и состояниями
  ACTIVE/STALE/ORPHANED, session-scoped процессы (process groups) и порты,
  env-инъекция (GILDRA_*, PORT, COMPOSE_PROJECT_NAME) и Project Runtime
  Profile, controlled merge workflow (конфликты никогда не разрешаются
  молча), защита protected-веток на уровне менеджера, crash recovery без
  автоудаления, минимальная модель Task и локальный audit-лог; версионирован-
  ный API `/gildra/v1/*` со структурными кодами ошибок.
- Оверлей: постоянная идентификация Проект · Сессия · Ветка · Режим и панель
  Workspaces (создание изолированной сессии, Merge, безопасное завершение с
  dry-run-планом, восстановление ORPHANED); реестр upstream-селекторов;
  тяжёлые DOM-сканы таргетированы на поддерево фактических мутаций.
- Windows: вызовы corepack/npm переведены на JS-входы через node — shell
  убран полностью, пути с пробелами безопасны; macOS: deadline готовности
  Harness c диагностикой вместо вечного спиннера.
- Архитектура и безопасность задокументированы: словарь сущностей, восемь
  инвариантов изоляции, раздел SECURITY об Unix-изоляции пользователей.

### Надёжность и безопасность (серия исправлений по аудиту upgrade.md)

- Windows: установщик падает при ошибке любой нативной команды (Invoke-Checked),
  маркер версии недостижим при провале; самообновление переведено на безопасные
  PowerShell-вызовы (временный .ps1 + -File, литеральный фильтр процессов,
  валидация цели остановки); эксклюзивный лок обновления; успешный статус не
  затирается ошибкой перезапуска.
- UI-оверлей: устранена вечная петля observer → rAF → рендер (идемпотентные
  DOM-записи, доказано поведенческими тестами); удалён 500-мс поллинг переводов;
  экспоненциальный backoff фонового SSH; переводы уважают явный выбор English;
  React-узлы не удаляются физически; ошибка старта agent-control больше не
  роняет процесс Harness.
- Безопасность: чтение файлов workspace через файловый дескриптор с O_NOFOLLOW
  и полной симлинк-матрицей тестов; skill-installer закрепляет источники по
  commit SHA; guard verify.sh запрещает любые не-SHA ref у GitHub Actions;
  модель доверия загрузок задокументирована в SECURITY.md; sentinel-преаудит
  больше не обходится совпадением версии с чужим пакетом; guard install root
  не обходится хвостовым слэшем.
- CI: ошибки парсинга PowerShell аккумулируются по всем скриптам; Windows-джоба
  гоняет node-тесты и failure-path smoke настоящим PowerShell 5.1; Linux-джоба
  исполняет серверный установщик end-to-end; новая lint-джоба (eslint,
  prettier, DOM-тесты, shellcheck, PSScriptAnalyzer).
- Тесты: жизненный цикл applyUpdate (9 сценариев), лок, PowerShell-слой,
  симлинк-матрица патча, поведенческие DOM-тесты на happy-dom.
- Инструментарий: корневой package.json (npm test/verify/lint), ESLint с
  correctness-правилами, lib/client.js собирается детерминированно из
  20 модулей src/client/ (zero-dep build + --check в verify.sh).
- Гигиена: артефакты аудитов перенесены в artifacts/, script/ влит в scripts/,
  удалены мёртвый runtime/python и личные пути/SSH-алиасы из кода и доков.

### Добавлено

- Единая архитектура Kit Manifest → Desktop Host → Harness Overlay.
- Локальные и SSH-среды, серверная синхронизация, безопасные обновления и восстановление Harness.
- Пресеты агентов, авто-ревью, автоматизации, терминал, MCP, Skills, RAG, GitHub, Archify и CodeGraph.
- Нативная оболочка macOS и установочный комплект Linux-сервера.

### Изменено

- Свёрнутый системный монитор приведён к компактному состоянию 30×30 px и получил доступную подпись.
- Публичная документация дополнена правилами участия, политикой безопасности и шаблонами issue/PR.
- GitHub Actions закреплены по полным commit SHA и получают минимальные разрешения.
- README получил короткий путь первого запуска и актуальный снимок desktop-приложения.

### Исправлено

- Полный русский пользовательский путь, компактный Context Doctor и практичный центр агентов.
- Безопасные границы импорта репозиториев, updater, Host RPC, SSH и установки плагинов.
- Серверный запуск теперь использует `workspace-write`; файловый preview принимает только зарегистрированные рабочие папки и закрыт по умолчанию на многопользовательском Linux-сервере.
