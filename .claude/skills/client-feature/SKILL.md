# Правка overlay-плагина ui-compact

`lib/client.js` — **generated-артефакт**: он собирается конкатенацией
фрагментов `src/client/*.js` командой `node scripts/build-ui-client.mjs`
(verify.sh гоняет `--check`). Правь фрагмент, пересобирай, коммить и фрагмент,
и собранный файл. В браузер он грузится одним файлом через
`window.__ModuleLoader__.load` (import внутри недоступен), `index.js` — cordis-
плагин с маршрутами `/gildra/*`. Всё крутится на одном MutationObserver +
rAF-коалесинге (страховочный проход — раз в 30 с), поэтому главные риски —
петли рендера и рассинхрон с контрактами.

## Контракты, которые ломаются молча

1. **Реестр фич.** Состав и порядок `OVERLAY_FEATURES` в client.js обязан
   совпадать с `overlay.features` в `config/kit.json`.
   `scripts/kit-config.test.mjs` вырезает реестр регексом между якорями
   `const OVERLAY_FEATURES` и `function applyUiEnhancements` — не переименовывай
   и не перемещай эти два идентификатора относительно друг друга.
2. **Тесты-регексы.** `plugins/gildra-dsh-ui-compact/test.mjs` содержит ~60
   `assert.match` по тексту client.js. Перед переименованием или переносом
   любой функции грепни её имя в test.mjs и обнови ассерты вместе с кодом.
   Красный тест после рефакторинга — почти всегда устаревший регекс, а не
   сломанное поведение; но проверь, прежде чем править ассерт.
3. **Одна фича — одна feature-группа** (`docs/architecture.md`). Доступ к ОС —
   только через версионированный Host RPC с web-fallback; передавать в host
   shell-команды, credentials или непроверенные URL запрещено.

## Правила работы с DOM (причины — реальные баги этого файла)

- **Пиши только при изменении.** Перед `el.textContent = v`,
  `setAttribute`, `style.*` сравни с текущим значением. Безусловная запись —
  даже той же строки — пересоздаёт узел, будит MutationObserver и запускает
  вечную петлю «мутация → полный проход → мутация».
- **Не удаляй чужие узлы.** Элементы Harness рендерит React; `.remove()`
  вызывает NotFoundError при реконсиляции. Прячь через CSS-класс.
- **Не пиши `.value` контролируемых инпутов** — расходится с React-состоянием
  и с тем, что уйдёт при сабмите.
- **Динамика — только `textContent`/`setAttribute`.** `innerHTML` допустим
  исключительно для статических шаблонов без данных.
- Слушатели диалогов снимай в `close()` (в файле это уже дисциплинированно —
  сохраняй паттерн); долгоживущие Map чисти при закрытии сессий.

## Селекторы upstream и переводы

- Новый селектор вёрстки Harness добавляй с комментарием, какая фича сломается
  при его исчезновении. Предпочитай `[data-slot=…]`-атрибуты; поиск по
  локализованному тексту кнопок — крайняя мера (ломается на каждом языке).
- Переводы — в первую очередь через `ctx.locale.register` (штатный i18n);
  DOM-перезапись словарями — последнее средство, и она обязана проверять
  `ctx.locale.getLocale()`, чтобы не русифицировать английский интерфейс.

## После правки

1. `node --check` обоих файлов, затем
   `node plugins/gildra-dsh-ui-compact/test.mjs` (или полный
   `./scripts/verify.sh`).
2. Менялся client.js → подними `version` в `package.json` плагина, иначе
   браузеры пользователей останутся на кэшированной версии.
3. Живая проверка: `script/build_and_run.sh` пересобирает и перезапускает
   desktop-приложение; проверь фичу и консоль на ошибки.
