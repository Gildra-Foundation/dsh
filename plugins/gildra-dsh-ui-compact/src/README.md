# Исходники client.js

`lib/client.js` — генерируемый файл: он собирается конкатенацией фрагментов
`src/client/*.js` в лексикографическом порядке имён командой

    node scripts/build-ui-client.mjs

Руками `lib/client.js` не правится. Порядок работы:

1. Правьте нужный фрагмент в `src/client/` (числовой префикс задаёт порядок склейки).
2. Пересоберите: `node scripts/build-ui-client.mjs`.
3. Прогоните проверки: `./scripts/verify.sh` (он гоняет `build-ui-client.mjs --check`,
   который падает, если `lib/client.js` разошёлся со сборкой из фрагментов).

Фрагменты — не самостоятельные модули, а вербатимные куски одного файла-фабрики
`window.__ModuleLoader__.load(...)`: обвязка открывается в `00-header.js`
и закрывается в `90-registry.js`, поэтому по отдельности они не парсятся.
