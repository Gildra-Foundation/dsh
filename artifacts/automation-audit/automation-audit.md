# Аудит центра автоматизаций

## Область проверки

- Продукт: Gildra DSH / `dsh-automation` 0.1.7.
- Задача пользователя: быстро создать проверку кода, свежести данных или восстановление парсера, выбрать модель, расписание и уровень доступа.
- Проверенный путь: вход из боковой панели → пустой список → создание по шаблону → выбор модели → отмена без сохранения.
- Среда: локальное приложение, тёмная тема, ParserUnix, узкий viewport 487 × 743 CSS px.

## Шаги и состояние

1. **Вход из новой сессии — требует улучшения.** Исходный плагин не создаёт глобальный экран и требует хотя бы одного сообщения, потому что вкладка автоматизаций привязана к DSH-сессии.
2. **Обзор автоматизаций — исправлено.** Добавлены русские подписи, компактные показатели и блок быстрого запуска; чат-композер больше не перекрывает центр автоматизаций.
3. **Создание — исправлено.** Длинная встроенная форма заменена фокусным прокручиваемым диалогом с закреплённой кнопкой создания.
4. **Выбор сценария — исправлено.** Добавлены три готовых шаблона: проверка кода, проверка новых данных и контролируемое восстановление парсера.
5. **Модель и доступ — проверено.** Выбор GPT-5.6-Sol включает список глубины рассуждения; шаблон парсера выбирает `workspace-write`, безопасные проверки — `read-only`.

## Основные проблемы и решения

- **P1 — автоматизации недоступны до первого сообщения.** Ограничение остаётся на уровне архитектуры session-scoped view. Текст ошибки сделан понятнее; после появления сессии кнопка боковой панели снова открывает русскую вкладку напрямую.
- **P1 — пустой экран не подсказывал безопасный сценарий.** Добавлены три преднастроенных шаблона с разными границами доступа.
- **P2 — форма терялась под композером и требовала долгой прокрутки.** Форма стала отдельным прокручиваемым диалогом; композер скрывается только на вкладке автоматизаций и возвращается на вкладке Chat.
- **P2 — англоязычные технические подписи.** Основной путь локализован на русский, включая модель, reasoning, расписание и разрешения.
- **P2 — слишком много вертикального места занимали показатели.** Карточки статистики уплотнены.

## Доступность

- Сохранены нативные `button`, `select`, `radio`, `textarea`, фокусная обводка и доступные имена.
- Диалог прокручивается на узком экране, кнопка создания остаётся видимой.
- Полная клавиатурная и screen-reader проверка не выполнялась; вывод о полном соответствии WCAG не делается.

## Граница проверки

Реальная автоматизация не создавалась и расписание не включалось, чтобы не запускать фоновую задачу без отдельного согласования. Заполнение шаблона, выбор модели, включение reasoning и отмена формы проверены в браузере.
