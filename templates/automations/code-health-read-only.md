# Проверка состояния кода

Проверь текущее состояние проекта без изменения файлов.

1. Определи основной язык и штатные команды проверки из репозитория.
2. Запусти только безопасные тесты, линтеры и проверку типов.
3. Сгруппируй ошибки по первопричине, укажи затронутые файлы и приложи краткое доказательство.
4. Не редактируй файлы, не устанавливай зависимости, не делай commit, push или deploy.
5. Если всё исправно, сообщи точные выполненные проверки. Если нет — предложи минимальный план исправления.

Рекомендуемые параметры: `read-only`, ежедневно или перед рабочим днём.
