# Gildra DSH Kit

Воспроизводимая сборка DeepSeek Harness из исходников для macOS и Windows. Комплект устанавливает отдельное окружение в домашний каталог пользователя и не переносит пароли, OAuth-сессии, токены, историю чатов или приватные рабочие файлы.

## Что входит

- DeepSeek Harness `0.1.1-rc.2`, закреплённый на commit `b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`.
- Профиль **Engineering** с Codex и Claude Code subagents.
- Конструктор пользовательских пресетов: имя, системный промпт, модель и глубина рассуждения; при выборе пресета модель переключается автоматически.
- `dsh-team` 0.2.7: постоянные именованные саб-агенты, распределение задач, сообщения между участниками, общая доска и отдельная вкладка команды.
- `@perrylink/dsh-github` 0.6.5: поиск и чтение репозиториев, файлов, issues и pull request, создание PR, review, merge и работа с CI. Все операции записи требуют подтверждения пользователя; автоматический commit отключён.
- `workspace-files-explorer`: отдельная кнопка **Файлы проекта**, дерево текущей рабочей папки и безопасный предпросмотр кода/Markdown без изменения файлов. Для Harness 0.1.1-rc.2 применяется небольшой read-only адаптер: реальные пути проверяются после раскрытия символических ссылок и не могут выйти за границы проекта.
- `dsh-agent-sync`: импорт пользовательских Skills и MCP-конфигураций из Codex и Claude Code.
- `@michengai/dsh-skills-manager` 0.1.24: готовая панель просмотра, загрузки, включения и удаления локальных Skills.
- Инструмент `install_skill_from_github`: ИИ проверяет GitHub-источник и SHA-256, показывает предупреждения и устанавливает Skill только после подтверждения в приложении.
- `@openma/dsh-agents-plugins-bridge` 0.0.7: обнаружение и контролируемый импорт установленных Codex/Claude plugins, marketplaces, skills, MCP, hooks, commands и agents.
- `@goodandready/dsh-russian-lang` 0.1.2: русский язык в штатном переключателе и перевод основных экранов Harness.
- Дополнительный русский словарь Gildra для MCP/Навыков, плагинов агентов, автоматизаций, контекста и упоминаний файлов.
- Брендированный стартовый экран **Gildra Coding**.
- Интернет-поиск и `web_fetch`, GenUI, Archify, вкладка **Карта кода**, CodeGraph, Context, Context Doctor, Security Audit и `@file`.
- `@syncended/dsh-automations` 0.8.7: глобальный центр фоновых Agent-задач, который работает без открытого чата; расписания, история запусков, выбор модели, reasoning, режима доступа, очередей и поведения после пропущенного запуска.
- Готовые шаблоны проверки кода, свежести данных и контролируемого восстановления парсера.
- Компактный Context Doctor: индикатор 31×27 px и небольшая открываемая панель до 320×420 px.
- Нативная оболочка macOS и ярлык desktop-app для Windows через Edge WebView; локальный сервер запускается скрыто без открытия браузера.

## Установка

### macOS

Скачайте архив `Gildra-DSH-macOS.zip`, распакуйте и дважды нажмите `Install Gildra DSH.command`.

Окружение устанавливается в `~/.gildra-dsh`, приложение — в `~/Applications/Gildra DSH.app`. Сборка подписана ad-hoc и не нотарифицирована: для публичного распространения без предупреждения Gatekeeper нужен сертификат Apple Developer ID и notarization.

### Windows

Скачайте `Gildra-DSH-Windows.zip`, распакуйте и запустите `Install Gildra DSH.cmd`. Установщик скачает закреплённый portable Node.js, исходники Harness и плагины, затем создаст ярлык **Gildra DSH** на рабочем столе.

CodeGraph включается автоматически, если найден `python3` на macOS или `python` в Windows. Без Python остаётся доступен Archify.

Чтобы получить карту проекта, попросите: «Используй Archify и построй карту этой кодовой базы». После проверки Archify ИИ автоматически отправит готовый локальный HTML во вкладку **Карта кода** рядом с «Чат» и «Траектория». Удалённые URL в предпросмотре запрещены: карта открывается только из проверенного HTML в рабочем проекте или из HTML, переданного самим ИИ.

## Первый запуск

Откройте **Settings → Subscriptions** и войдите в Codex и/или Claude. Учётные данные создаются отдельно на каждом компьютере и никогда не находятся в репозитории.

Чтобы включить перевод, откройте **Settings → General → Language → Русский**. Выбор сохраняется после перезапуска приложения.

В **Настройки → MCP/Навыки** можно просканировать Codex и Claude Code и выбрать, какие навыки или MCP-серверы перенести. Установленные сторонние плагины обнаруживаются в **Настройки → Плагины агентов**; импорт запускается только вручную, чтобы неизвестные hooks и расширения не начали выполняться без проверки.

В **Настройки → Навыки** можно вручную управлять локальными Skills. Также достаточно попросить ИИ: «Найди Skill для проверки API и установи его». ИИ найдёт точную папку на GitHub, проверит структуру и рискованные шаблоны, после чего приложение покажет источник, ревизию и SHA-256. Без нажатия **Установить** файлы не меняются; скрипты Skill во время установки не запускаются.

В **Настройки → Пресеты агента → Создать пресет** задайте роль, системный промпт, модель и глубину рассуждения. Новый пресет появляется в переключателе над полем сообщения; закреплённая модель применяется сразу при его выборе в пустой сессии.

Для большой задачи попросите главного агента создать команду и раздать роли, например: «Создай команду из архитектора, разработчика и тестировщика, разбей задачу и веди общую доску». После первого `team_spawn` появится вкладка **Команда агентов** со статусами участников, задачами, перепиской и общими заметками.

GitHub-интеграция сначала использует локальную авторизацию `gh`. Если сотрудник ещё не вошёл, достаточно один раз выполнить `gh auth login`; альтернативно токен можно сохранить в защищённом хранилище через **Настройки → Плагины → GitHub**. Секрет не попадает в `settings.yaml`, установщик или репозиторий. Для просмотра исходников откройте рабочую сессию и нажмите **Файлы проекта** в её заголовке.

Автоматизации доступны из одноимённой кнопки в боковой панели сразу после запуска приложения — открывать чат предварительно не нужно. Сначала запускайте новую задачу кнопкой **Запустить сейчас** и проверяйте результат. Для фонового исправления кода используйте `workspace-write`; `danger-full-access` выбирайте только вручную для полностью доверенных задач.

Готовые безопасные шаблоны находятся в [`templates/automations`](templates/automations).

## Обновление и воспроизводимость

Все внешние исходники закреплены версиями или commit SHA в [`config/versions.env`](config/versions.env) и установщиках. Повторный запуск установщика обновляет пакеты, сохраняя отдельный DSH home. Перед изменением версий проверяйте совместимость с `0.1.1-rc.2`.

## Проверки

```bash
./scripts/verify.sh
```

Проверка валидирует конфигурацию, JavaScript, shell-скрипты, PowerShell на Windows runner и собирает macOS app. Полноценные Windows и macOS архивы создаёт GitHub Actions.

## Безопасность

- В репозитории нет `.dsh` пользователя, credentials, cookies, session logs или рабочих проектов.
- MCP-токены и заголовки не синхронизируются автоматически: выбранный импорт сохраняет их локально открытым текстом в конфигурации профиля, поэтому включайте только доверенные MCP-серверы.
- Обнаружение Codex/Claude plugins работает в режиме чтения. Копирование и активация конкретного плагина выполняются только после явного выбора пользователя.
- Автоматизации по умолчанию ограничены домашним каталогом пользователя; для обычных проверок используйте `read-only`, для локальных исправлений — `workspace-write`.
- Никакой автоматический commit, push, deploy, DNS-операции или вызов платного провайдера не включены по умолчанию.
- Операции записи GitHub (создание/изменение PR и issues, комментарии, merge) проходят через отдельное подтверждение в DSH; чтение репозитория и файлов остаётся read-only.
- Автоматическое восстановление парсера — одна ограниченная попытка с сохранением LKG и обязательной валидацией результата.

DeepSeek Harness и сторонние плагины сохраняют собственные лицензии. Desktop-оболочка основана на MIT-проекте `Carleo10032/deepseek-harness-mac`.
